## CUDA V2 (P70) — measured + gated

The V2 evidence-kernel work is gated by `DigestEquivalenceHarnessV1` (any kernel must reproduce the CPU
reference's lane digests / Merkle root / `evidence_root` / replay byte-for-byte). Measured on the RTX
4080 SUPER: V2-A lane-batching (digest-identical; occupancy 8%→52%), V2-B segment-parallel (opt-in
`evidence_root_v2`; deep 1024×8192 case ~18× kernel, ~8× end-to-end with pinned H2D). A `cudaMemcpyAsync`
overlap was measured 2.7× slower and reverted (disclosed). Full before/after counters:
`docs/cuda_evidence_kernel_v2_design.md` + `crates/dsfb-chemical-engineering-cuda/reports/NSIGHT_SUMMARY.md`.
