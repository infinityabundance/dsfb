S-PERF.2 LayerAResidentPipelineV1 — Summary Receipt
====================================================

Panel verdict: post-S-PERF.1 panel directive (2026-05-17).
Sealed under the 10-step per-section discipline ritual.

Commit identity (panel-locked):

    S-PERF.2 builds the first Layer-A device-resident
    evidence pipeline so traffic receipts can measure GPU
    evidence production without host JSON, report rendering,
    transcript construction, or court explanation time
    mixed in.

Panel-locked verdict (verbatim):

    S-PERF.1 gave the ruler; S-PERF.2 isolates the GPU
    evidence-factory path the ruler will measure.

Core rule:

    Layer-A measures evidence production only:
    EvidenceDensor → WitnessDensor → FusionDensor →
    CandidateDensor + digests. No host-side transcript. No
    JSON/report timing. No CaseFileV2 materialization. No
    semantic admission timing.

----------------------------------------------------------------
Court-delta posture
----------------------------------------------------------------

S-PERF.2 ships ONLY the pipeline schema + residency receipt +
traffic-receipt envelope + verifier + builder + renderers.
The first actual measurement against this pipeline is a
separate S-PERF.3+ commit gated on the public-data
saturation bundle work.

  - LayerAResidentPipelineV1
    Pipeline schema declaring the stage sequence, per-densor
    residency policy, and panel-locked forbidden-host-
    activity flags. Five stages
    (EvidenceDensorProjection / WitnessDensorEvaluation /
    FusionDensorReduction / CandidateDensorCollapse /
    StageDigestEmission), five per-densor residency
    declarations, five forbidden-host-activity flags (all
    must be false for Layer-A admission).

  - LayerADeviceResidencyReceiptV1
    Per-densor H2D / D2H byte accounting for one pipeline
    run. References the pipeline schema by hash so the
    verifier can cross-check residency-class declarations
    against measured D2H bytes (negative #4: full witness
    D2H dump).

  - LayerATrafficReceiptV1
    Top-level META-hash envelope binding pipeline +
    residency receipt + a referenced S-PERF.1
    `DeviceTrafficReceiptV1` (by hash) + the
    court-authority hash anchors the pipeline promises NOT
    to mutate. One hash pins the entire Layer-A measurement
    chain.

  - LayerADensorKind enum: Evidence / Witness / Fusion /
    Candidate / StageDigest. The five categories cover the
    entire Layer-A H2D / D2H byte surface.

  - DeviceResidencyClass enum: DeviceResidentOnly /
    DeviceResidentWithCompactD2H / HostMaterialized. Layer-A
    rejects HostMaterialized on any densor.

Eight panel-required load-bearing negatives
----------------------------------------------------------------

  1. s_perf_2_rejects_layer_a_receipt_with_host_json_time
       — pipeline with `host_json_emission_present=true`.
  2. s_perf_2_rejects_layer_a_receipt_with_casefile_materialization_time
       — pipeline with `casefile_materialization_present=true`.
  3. s_perf_2_rejects_pipeline_without_device_residency_declaration
       — pipeline with empty residency_declarations.
  4. s_perf_2_rejects_d2h_full_witness_dump_when_summary_only_declared
       — residency receipt declares D2H bytes > 0 for a
         densor whose pipeline declaration is
         DeviceResidentOnly (catches full Witness / Fusion /
         Evidence dump masquerading as Layer-A).
  5. s_perf_2_rejects_missing_h2d_d2h_byte_accounting
       — residency receipt has empty per-densor H2D AND
         empty per-densor D2H lists (no byte accounting).
  6. s_perf_2_rejects_cuda_timing_method_not_allowed_by_s_perf_1
       — inner DeviceTrafficReceipt timing_method is neither
         CudaEvent nor CudaStreamSync.
  7. s_perf_2_rejects_layer_a_claim_without_device_traffic_receipt
       — traffic receipt has
         device_traffic_receipt_hash_v1 == [0; 32].
  8. s_perf_2_rejects_pipeline_that_mutates_court_authority_hashes
       — pipeline with
         `mutates_court_authority_hashes=true`.
