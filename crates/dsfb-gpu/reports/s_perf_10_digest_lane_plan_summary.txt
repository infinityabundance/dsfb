What this DOES
--------------

  - Parses the four `tree_digest` rows from
    reports/d64_stage_timing_256x4096_K1.txt (us +
    percent-of-device-total) and computes digest_total_us
    + digest_total_pct.
  - Builds the panel-locked digest-root preservation
    contract: four declared laws (same-mode digest root,
    canonical fragment merge order, digest-mode
    non-aliasing, casefile chain preservation) that any
    future digest rewrite MUST satisfy.
  - Binds the parsed audit + contract + upstream S-PERF.6
    baseline hash + S-PERF.7 verifier hash + S-PERF.8.1
    receipt hash + R.12b full-scale episode pin (1917)
    into a single hashable DigestLanePlanV1 envelope.

Preservation contract (panel-locked; folded into
`digest_compaction_contract_hash_v1`)
---------------------------------------

  same_mode_digest_root_law:
    Future digest compaction MUST preserve byte-identical
    digest roots within the declared digest mode. A
    TreeSha256V1 rewrite MUST preserve TreeSha256V1
    roots. A SerialSha256 path MUST preserve SerialSha256
    roots. Cross-mode root equality is NOT required.

  canonical_fragment_merge_order_law:
    Per-block digest fragments MUST be merged in canonical
    order; completion-order merging is panel-forbidden.

  digest_mode_non_aliasing_law:
    Digest mode identifiers (SerialSha256 / TreeSha256V1
    / TreeSha256V2 / ...) MUST NOT alias to roots from a
    different mode; each declared mode owns its own
    root-byte projection. Mode identity is preserved
    within the mode; cross-mode roots are NOT required to
    match.

  casefile_chain_preservation_law:
    CaseFile per-stage hash chain MUST stay byte-identical;
    no digest rewrite may insert, remove, or reorder the
    12 chain links.

Parser strictness
-----------------

The parser asserts every panel-pinned label appears in
the source report. The detector label is the long form
`tree_digest detector (wide cells)`; the parser matches
this prefix exactly so a future kernel rename surfaces
as a stage-label-mismatch verifier rejection. Pct column
is X.Y or X.YY decimal form; anything else surfaces as
MalformedNumber.
