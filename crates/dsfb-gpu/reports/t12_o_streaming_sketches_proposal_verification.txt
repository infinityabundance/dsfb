Hash / width / depth / seed contract discipline coverage
----------------------------------------------------------------

The t12_o_rejects_sketch_without_hash_family_width_depth_or_
seed_contract test partitions the 8 CanonicalAddition records
into three contract families:

1. Hash-based seeded sketches (CMS 6501, Bloom 6503, AMS 6508)
   must declare: hash family + width / bucket count / bit-
   array size + per-row or per-sketch seed array.
2. HyperLogLog (6502) has a single hash function with a
   declared precision parameter (m = 2^precision); the test
   requires hash family + bucket count + precision parameter
   + harmonic-mean estimator. No separate "seed array" is
   required because HLL uses one hash function.
3. Deterministic-counts / deterministic-tuple sketches
   (Misra-Gries 6504, Space-Saving 6505, Greenwald-Khanna
   6506, t-digest 6507) must declare: width contract (k
   counter slots / epsilon error bound / compression delta) +
   update rule (decrement-on-miss / replace-smallest-on-miss
   / tuple-insertion rule / centroid scale function) + merge
   law.
