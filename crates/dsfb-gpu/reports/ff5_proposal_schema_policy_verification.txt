Panel-required load-bearing negatives (9)
----------------------------------------------------------------

R.1  SchemaRerenderWithoutOldHash
     Reject any migration row whose old_artifact_hash is the
     all-zero sentinel.
     Test: ff5_rejects_schema_rerender_without_old_hash

R.2  SchemaRerenderWithoutNewSchemaHash
     Reject any receipt with empty new_schema_version OR any
     migration row with all-zero new_artifact_hash.
     Test: ff5_rejects_schema_rerender_without_new_schema_hash

R.3  SchemaRerenderWithoutMigrationTable
     Reject any receipt with empty migration_rows.
     Test: ff5_rejects_schema_rerender_without_migration_table

R.4  SchemaRerenderWithoutReason
     Reject any receipt with empty semantic_reason OR any
     migration row with empty reason_byte_diff.
     Test: ff5_rejects_schema_rerender_without_reason

R.5  MigrationTableWithDuplicateOldHash
     Reject any migration table (across receipt rows or the
     whole rolling table) with two rows sharing the same
     old_artifact_hash.
     Test: ff5_rejects_migration_table_with_duplicate_old_hash

R.6  MigrationTableWithDuplicateNewHash
     Reject any migration table with two rows sharing the same
     new_artifact_hash.
     Test: ff5_rejects_migration_table_with_duplicate_new_hash

R.7  ClaimThatOldArtifactHashWasInvalid
     Reject any receipt with declares_old_artifact_hash_valid
     = false. A migration is a schema evolution, not a
     correction; the old hash was valid at filing time.
     Test: ff5_rejects_claim_that_old_artifact_hash_was_invalid

R.8  SchemaUpgradeThatMutatesCorpusHashV1
     Reject any receipt with preserves_corpus_hash_v1 = false.
     corpus_hash_v1 is the historical seed-corpus anchor
     frozen at T.10; no schema upgrade may mutate it.
     Test: ff5_rejects_schema_upgrade_that_mutates_corpus_hash_v1

R.9  SchemaUpgradeThatMutatesCorpusHashV2WithoutFreezeCampaign
     Reject any receipt with preserves_corpus_hash_v2 = false
     and freeze_campaign_id = None. corpus_hash_v2 mutation
     requires a declared freeze campaign.
     Test: ff5_rejects_schema_upgrade_that_mutates_corpus_hash_v2_without_freeze_campaign

Plus admit-with-freeze-campaign test:
  ff5_admits_schema_upgrade_that_mutates_corpus_hash_v2_with_freeze_campaign
