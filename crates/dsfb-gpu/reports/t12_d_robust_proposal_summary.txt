================================================================
T.12.d - Robust Statistics amendment proposal summary
================================================================

Panel-locked thesis. T.12.d files the Robust Statistics
amendment proposal. It resolves robust z / MAD aliases against
the existing SEED canonical, admits only robust primitives with
explicit estimator, window, trimming, quartile, or pair-
selection laws, rejects stochastic RANSAC-style claims unless
deterministically reduced, and preserves the frozen T.10
corpus hash.

Main panel instruction: "Robust-statistics names are alias-
heavy. Make estimator law explicit, or collapse / defer."

----------------------------------------------------------------
Major architectural milestone
----------------------------------------------------------------

T.12.d is the **first proposal to exercise ALL FIVE
panel-locked court-delta categories**:

  CanonicalAddition                       (introduced T.12.0)
  ExistingCanonicalAuthorityResolution    (introduced T.12.b)
  DomainTransferOf                        (introduced T.12.b)
  ParameterizationOf                      (introduced T.12.c)
  RejectedNotDeterministic                (introduced T.12.b)

The wire-name set is now closed at five categories.

Estimator-law contract declarations (panel-required)
----------------------------------------------------------------

Per the panel's main instruction, every CanonicalAddition and
ExistingCanonicalAuthorityResolution record declares its
estimator-law contract in the reason text. The acceptance
suite pins each declaration under a dedicated load-bearing
negative:

  Theil-Sen        : pair-selection + slope-median + tie-break
                     + window laws  -> pinned by
                     t12_d_rejects_theil_sen_without_pair_selection_law
  Biweight midvar. : tuning constant + convergence threshold +
                     iteration count + numeric mode
                     -> pinned by t12_d_rejects_biweight_midvariance_
                        without_tuning_and_convergence_law
  Trimmed mean     : trim fraction + symmetric/one-sided +
                     percentile/count semantics + tie-break
                     -> pinned by t12_d_rejects_trimmed_mean_
                        without_trim_fraction_law
  Winsorized mean  : winsor limit + replacement-rule + tie-
                     break
                     -> pinned by t12_d_rejects_winsorized_mean_
                        without_winsor_limit_law
  Robust z (SEED 6): median + MAD + threshold multiplier +
                     window
  Hampel    (SEED 7): windowed local median + MAD + threshold
                     + replacement/rejection rule
                     -> pinned by t12_d_rejects_hampel_as_canonical_
                        without_windowed_local_median_law
  Tukey     (SEED 18): quartile estimator + IQR multiplier +
                     inclusive/exclusive fence + tie-handling
                     -> pinned by t12_d_rejects_tukey_fence_
                        without_quartile_law
  RANSAC    (5408)  : declaration of the four reduction
                     requirements (seed + schedule +
                     iteration budget + tie-break)
                     -> pinned by t12_d_rejects_ransac_without_
                        deterministic_seed_and_schedule

Panel-locked non-claims
----------------------------------------------------------------

T.12.d does NOT:
- mutate corpus_hash_v1 (35c276c7...);
- mutate registry_hash_v2 or any T.11/S1.3/T.12.0/T.12.a/
  T.12.b/T.12.c hash or any DetectorPassport hash;
- create corpus_hash_v2;
- duplicate robust-z / Hampel / Tukey fences (the three
  ExistingCanonicalAuthorityResolution records + the
  parametric collision-loop test prevent it);
- promote modified z-score / rolling Hampel / k x IQR fence
  to new_canonical_records (each is ParameterizationOf);
- promote RANSAC to new_canonical_records (rejected as
  RejectedNotDeterministic; the four reduction requirements
  must be declared in a future T.12.x proposal);
- claim a robust-statistics primitive without declared
  estimator law (every record's reason text declares its
  specific operational contract);
- duplicate the SCD / drift / distribution-distance
  primitives T.12.b / T.12.c admitted;
- activate new detectors (S1.3a planner not re-emitted);
- execute on GPU (corpus crate stays host-only and zero-dep);
- claim empirical usefulness for the new primitives (T.8
  ledger stays NotScored for the 4 new canonicals).
