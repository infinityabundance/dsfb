================================================================
T.12.c - Drift Detection / Distribution-Distance Authority
        amendment proposal summary
================================================================

Panel-locked thesis. T.12.c files the Drift Detection /
Distribution Distance amendment proposal. It adds only
deterministic drift-distance primitives whose reference-
distribution, windowing, binning, and sampling contracts are
declared; resolves collisions with existing SEED records;
classifies streaming drift algorithms as canonical,
parameterized, domain-transfer, or deferred without mutating
the frozen T.10 corpus.

Main panel instruction: "Do not count method names. Count
distinct deterministic decision functionals with declared
reference / window / sampling contracts."

SEED collision walk (the panel-required first step)
----------------------------------------------------------------

T.12.c's design began with the panel-required
`t12_c_detects_existing_seed_collisions_before_new_canonical_assignment`
walk. A grep of `seed.rs` for every candidate name in the
panel's draft list found ELEVEN distribution-distance
primitives already canonical:

   8  Kolmogorov-Smirnov two-sample test
   9  Kullback-Leibler divergence
  10  Maximum Mean Discrepancy (MMD)
  26  Anderson-Darling test
  27  Cramer-von Mises test
  28  Wasserstein / earth-mover distance
  29  Energy distance
  30  Hellinger distance
  31  Population Stability Index (PSI)
  32  Jensen-Shannon divergence
  33  Total variation distance

All eleven are recorded as
`ExistingCanonicalAuthorityResolution` records. Of the
remaining candidates (ADWIN, DDM, EDDM, HDDM, KSWIN, Kuiper),
the court ruled four are canonical additions and two are
parameterizations of existing canonicals.

----------------------------------------------------------------
Why 4 new canonicals, not the panel-draft's 14
----------------------------------------------------------------

The panel's draft candidate list named 14 method names: ADWIN,
DDM, EDDM, HDDM, KSWIN, Kuiper, plus the eight distribution-
distance methods already in SEED. The SEED walk caught the
eleven already-canonical methods at intake. Of the six
remaining candidates, the court ruled:

- Four are CanonicalAddition (Kuiper, ADWIN, DDM, HDDM — each
  with a structurally distinct decision functional and a
  declared deterministic contract).
- Two are ParameterizationOf (EDDM is the DDM family with a
  different inner statistic; KSWIN is streaming-windowed KS).

Net result: 4 new canonicals + 11 existing-canonical authority
resolutions + 1 DomainTransferOf + 2 ParameterizationOf = 18
dedup-court records.

----------------------------------------------------------------
Declared deterministic contracts (panel-required language)
----------------------------------------------------------------

Every CanonicalAddition / ExistingCanonicalAuthorityResolution
record carries reference-distribution / reference-window /
adaptive-partition / ordered-stream contract language in its
reason text. Specific declarations:

  Kuiper    : reference-window pair; deterministic statistic.
  ADWIN     : adaptive-window pair, Hoeffding delta, cut +
              window-merge tie-break rule; deterministic
              throughout; no probabilistic sampling.
  DDM       : ordered binary error sequence + running-minimum
              reference window; deterministic.
  HDDM      : ordered binary error sequence + running-minimum
              reference window + declared Hoeffding-bound
              confidence delta; deterministic.
  PSI       : declared binning law (bin edges, bin count,
              empty-bin treatment) + reference distribution.
  KL / JS   : reference distribution required.
  Hellinger : reference distribution required.
  TV        : reference distribution required.
  KS / AD / CvM / Wasserstein / Energy / MMD :
              reference window pair (or reference distribution)
              required.

The acceptance suite pins these contract declarations under
`t12_c_rejects_distribution_distance_without_reference_distribution_requirement`
and `t12_c_rejects_psi_without_binning_law` load-bearing
negatives.

Panel-locked non-claims
----------------------------------------------------------------

T.12.c does NOT:
- mutate `corpus_hash_v1` (35c276c7...);
- mutate `registry_hash_v2`, any T.11/S1.3 hash, any
  T.12.0/T.12.a/T.12.b hash, or any DetectorPassport hash;
- create `corpus_hash_v2`;
- promote EDDM or KSWIN to `new_canonical_records` (both are
  recorded as `ParameterizationOf` — promotion deferred to
  future T.12.x proposals if their family-distinct decision
  functionals warrant it);
- duplicate any already-canonical SEED distribution-distance
  primitive (the eleven authority-resolution records prevent
  it; the parametric collision-loop test pins the rule);
- claim probabilistic / randomized distances as canonical
  without an explicit deterministic-reduction status (no such
  records appear in T.12.c; the load-bearing negative is the
  static-invariant assertion);
- claim a reference-distribution-free distance / divergence
  (every record declares its reference contract);
- duplicate the SCD primitives T.12.b admitted (Shiryaev-
  Roberts, GLR, Binary segmentation, PELT remain under the
  SCD source class only);
- activate new detectors (S1.3a planner not re-emitted);
- execute on GPU (corpus crate stays host-only and zero-dep);
- claim empirical usefulness for the new primitives (T.8
  ledger stays at NotScored for the 4 new canonicals).
