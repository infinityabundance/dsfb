Scope (panel-locked)
----------------------------------------------------------------
T.11e introduces an UNSIGNED, LOCAL, DSFB-NATIVE
ExecutionAttestationReceiptV1. It records the gates, toolchain,
hash-chain anchors, build commands, verification commands,
materials, subjects, and panel-locked non-claims for one
reproducibility-oriented run of the corpus + registry + court
stack. T.11e is NOT a SLSA / in-toto / SPDX / CycloneDX
compliance claim; it is an internal court-record for the
operator's own audit trail.

Verifier — 20 reject conditions
----------------------------------------------------------------
The 20-direction verifier rejects any receipt that:

  1. ZeroCorpusHash              — corpus_hash_v1 == [0u8; 32]
  2. ZeroRegistryHash            — registry_hash_v2 == [0u8; 32]
  3. ZeroPrecedentHash           — precedent_hash_v1 == [0u8; 32]
  4. ZeroGrammarHash             — admissibility_grammar_hash_v1
                                   == [0u8; 32]
  5. ZeroTranscriptHash          — trial_transcript_hash_v1
                                   == [0u8; 32]
  6. EmptyRepoCommit             — repo_commit is empty
  7. InvalidRepoCommitFormat     — repo_commit not 40-char lowercase
                                   hex
  8. DirtyRepoWithoutOverride    — repo_dirty AND NOT
                                   dirty_override_acknowledged
  9. EmptyBuildCommands          — build_commands is empty
 10. MissingRequiredGateCommand  — verification_commands missing
                                   any of Format / Clippy / Scrub /
                                   DocsFreshness / WorkspaceTest
 11. GateNotClean                — any of the five GateSummary
                                   booleans is false
 12. WorkspaceTestFailed         — workspace_failed > 0 OR
                                   workspace_groups == 0
 13. R12bEpisodeCountsDrift      — pinned counts != 13 / 89 / 1917
 14. ClaimedSlsaLevelPresent     — claimed_slsa_level.is_some()
 15. ClaimedSignedAttestation    — claimed_signed_attestation == true
 16. SubjectDigestMissing        — any subject digest is [0u8; 32]
 17. MaterialDigestMissing       — any material digest is [0u8; 32]
 18. ReceiptHashMismatch         — receipt_hash_v1 disagrees with
                                   compute_execution_attestation_hash_v1
 19. NonClaimsIncomplete         — non_claims missing any required
                                   AttestationNonClaim variant
 20. HashChainCrossCheckFailed   — declared subject hashes do not
                                   match the corresponding hash-chain
                                   anchors

----------------------------------------------------------------
Panel-locked non-claims (verifier-enforced)
----------------------------------------------------------------
The receipt MUST carry every variant in AttestationNonClaim::
all_required():

  - UnsignedLocalReceipt
  - NotSlsaComplianceClaim
  - NotInTotoSignedStatement
  - NotReleaseArtifact
  - NotThirdPartyVerified
  - NotReproducibleBuildProof
  - RecordsObservedEnvironmentOnly

T.11e is a deterministic operator-side reproducibility record. It
does NOT claim:

  - signed release artifact (no key, no detached signature);
  - SLSA build-level compliance (no provenance predicate type);
  - in-toto Statement layout (no DSSE envelope);
  - third-party verification (operator-only court of record);
  - reproducible-builds.org bit-for-bit binary reproducibility
    (records environment metadata only);
  - external-ecosystem interoperability (DSFB-native schema).

Signed / detached-signature variants are deferred to a later
commit; this is T.11e's "unsigned base" surface only.

What T.11e does NOT do (deferred)
----------------------------------------------------------------
  - Sign the receipt (no detached signature; no key material).
  - Emit a SLSA Provenance v1.0 predicate.
  - Emit an in-toto v1 Statement.
  - Emit a DSSE envelope.
  - Mint a CycloneDX BOM / SPDX SBOM.
  - Cross-validate with third-party attestation services.
  - Hash repo source-bytes (the corpus / registry / court
    materials are already hashed via their respective v1 anchors;
    the source-tree hash is left to T.11f+).
  - Land ChallengeDocket (T.11f), DetectorContraindicationReceipt
    (T.11g), or ActivationPlanner (S1.3).
  - Change any of: D16/D64/D128/D205 GPU behavior, Audit-mode
    golden hashes, corpus_hash_v1, registry_hash_v2,
    precedent_hash_v1, admissibility_grammar_hash_v1,
    trial_transcript_hash_v1, or any DetectorPassport hash.
